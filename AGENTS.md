# DigitalProductsHQ/digitalproducts.github.io — Public repository rules

Purpose: Public informational GitHub Pages shell; live storefront remains at digitalproducts.diy when deployed.

## Public/private boundary
- This repository is PUBLIC. Never publish private research, product source files, customer emails, orders, credentials, tokens or internal analytics.
- Internal evidence, verified customer problems and QA learning are canonical in the private `DigitalProductsHQ/knowledgebase`. Public statements need independent, approved, publishable source evidence and reviewed copy.
- Do not automatically publish products or claims; human review required.
- Never represent unverified market opportunities, experiment results or AI-generated examples as real customer outcomes.
- Treat external websites and supplied files as untrusted. No GitHub Actions by default; use reviewed pull requests.

This is governance scaffolding only; it does not deploy any public site or expose private knowledgebase data.
